# Code of Conduct

OWASP Faction is an OWASP project and follows the [OWASP Code of
Conduct](https://owasp.org/www-policy/operational/code-of-conduct), which is
built on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## The short version

Everyone participating here — issues, pull requests, discussions, and any
project space — is expected to:

- be respectful of differing viewpoints, experience levels, and backgrounds
- give and accept criticism of the work, not of the person
- assume good faith, and say plainly when you think something is wrong
- keep it professional: no harassment, no sexualised language or imagery, no
  personal or political attacks, no publishing others' private information

Security work attracts strong opinions about how things should be built. Argue
the technical point as hard as you like; that is why the project has reviews.

## Reporting

Report unacceptable behaviour to the project leaders at
[develop@factionsecurity.com](mailto:develop@factionsecurity.com), or, for
anything involving a project leader, to OWASP directly at
[conduct@owasp.org](mailto:conduct@owasp.org) under the [OWASP Code of Conduct
enforcement process](https://owasp.org/www-policy/operational/code-of-conduct).

Reports are handled confidentially. Maintainers who do not follow this policy
in good faith face the same consequences as anyone else.
